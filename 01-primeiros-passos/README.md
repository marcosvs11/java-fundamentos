# Primeiros passos

## Objetivo

Entender como um programa Java é escrito, compilado e executado.

## Conceitos

- JDK: Kit de desenvolvimento Java, que inclui o compilador e outras ferramentas necessárias para desenvolver aplicações Java.
- JVM: Java Virtual Machine, que executa o bytecode gerado pelo compilador Java.
- Bytecode: O código intermediário gerado pelo compilador java, que é interpretado pela JVM.
- Compilador: Ferramenta que transforma o código-fonte java em bytecode.
- Método main: Ponto de entrada de um programa Java, onde a execução começa.

## O que entendi

- Entendi sobre os conceitos de JDK, JVM, bytecode, compilador e método main. Além disso, aprendi que o código-fonte Java é escrito em arquivos com extensão `.java`, e que para executar um programa Java, é necessário primeiro compilá-lo para gerar o bytecode, que é então interpretado pela JVM. Ademais, estudei sobre a história do Java, que foi criado por James Gosling na Sun Microsystems em 1995, e que é uma linguagem de programação orientada a objetos, multiplataforma e amplamente utilizada no desenvolvimento de aplicações web, móveis e corporativas.
